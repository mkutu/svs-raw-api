## Workflow Commands Mapped to Tiers

```
┌─────────────────────────────────────────────────────────────┐
│              COMMAND                    TIER AFFECTED        │
├─────────────────────────────────────────────────────────────┤
│ check-missing                          NCSU + JUNO          │
│   → Scans NCSU and JUNO                                     │
│   → Identifies missing batches                              │
│                                                             │
│ sync <BATCH_ID>                        NCSU → JUNO          │
│   → Globus transfer                                         │
│   → Updates ncsu_sync_status                                │
│                                                             │
│ sync-all                               NCSU → JUNO (bulk)   │
│   → Multiple Globus transfers                               │
│   → Batch sync operations                                   │
│                                                             │
│ transfer <BATCH_ID>                    JUNO → Ceres         │
│   → Globus transfer                                         │
│   → Updates transfer_status                                 │
│                                                             │
│ process <BATCH_ID>                     Ceres (compute)      │
│   → SLURM job submission                                    │
│   → Snakemake pipeline                                      │
│   → Updates processing_status                               │
│                                                             │
│ full-pipeline <BATCH_ID>               All Tiers           │
│   → Checks NCSU sync need                                   │
│   → Transfers if needed                                     │
│   → Processes on compute                                    │
│   → Complete automation                                     │
└─────────────────────────────────────────────────────────────┘
```

## Parallel Processing Architecture

```
Ceres Compute Nodes

┌─────────────────────────────────────────────────────────────┐
│                    SLURM Job Scheduler                      │
└─────────────────────────────────────────────────────────────┘
           │
           │ sbatch run_snakemake_enhanced.sh
           │
           ▼
┌─────────────────────────────────────────────────────────────┐
│               Snakemake Workflow Manager                    │
│                                                             │
│  Dynamic DAG generation:                                    │
│  • Discovers all RAW files in batch                         │
│  • Creates conversion tasks                                 │
│  • Manages dependencies                                     │
│  • Handles failures and retries                             │
└─────────────────────────────────────────────────────────────┘
           │
           │ Spawns up to 12 parallel jobs
           │
    ┌──────┴──────┬──────┬──────┬──────┬──────┐
    │             │      │      │      │      │
    ▼             ▼      ▼      ▼      ▼      ▼
┌────────┐   ┌────────┐   ...  (12 jobs total)
│ Job 1  │   │ Job 2  │
│ 4 cores│   │ 4 cores│   Each job:
│ 16GB   │   │ 16GB   │   • RAW → DNG (Python)
│        │   │        │   • DNG → JPG (RawTherapee)
│ Process│   │ Process│   • Updates database
│ 1 image│   │ 1 image│   • Cleans up files
└────────┘   └────────┘

Total Resources at Peak:
• 48 CPU cores
• 192 GB RAM
• Processes 12 images simultaneously
```

```
┌────────────────────────────────────────────────────────────┐
│                    TIMING BREAKDOWN                        │
```
